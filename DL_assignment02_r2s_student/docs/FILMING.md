# 촬영 가이드 — 나눠 준 천을 휴대폰으로 찍기

천의 크기와 모양은 여러분이 직접 만듭니다: 천을 바닥에 평평하게 펴서 **사진 한 장**을 찍고 두 변을 자로 재면, 노트북 ⓪이 그 천의 메쉬를 만듭니다.
그다음 그 천을 두 손으로 들고 움직이는 영상을 찍습니다. 이 영상으로 **공기 저항**(값)과 **굽힘 강성의 상한**을 찾고, 교수님이 같은 천을 depth 카메라로 찍어 구한 값(비공개)과 비교합니다.

## 준비물

- 천. **줄자로 두 변을 2–3군데 재서 평균**, 가능하면 주방 저울로 질량도. 바닥에 평평하게 펴서 네 모서리가 보이는 사진 한 장 (메쉬용)
- 휴대폰과 **삼각대(또는 책 더미에 고정)**. 촬영 중 카메라가 움직이면 안 됩니다
- 인쇄한 체커보드 `docs/checkerboard_9x6_25mm.pdf` (100 % 크기로 인쇄, 한 칸이 25 mm인지 자로 확인), 딱딱한 판에 붙이기
- 천을 들어 줄 사람 1명 (찍는 사람과 따로)

## 휴대폰 설정 (중요)

| 설정 | 값 | 이유 |
|---|---|---|
| 방향 | **가로** | 파이프라인이 가로 영상(960 × 540으로 줄임)을 가정 |
| 해상도 / 프레임 | 1080p, 30 fps (60 fps도 가능) | |
| 렌즈 / 줌 | **기본(1×) 렌즈, 줌 없음** | 초점거리가 바뀌면 카메라 보정이 맞지 않음 |
| 손떨림 보정 (EIS / OIS 동영상 안정화) | **끄기** | 켜면 프레임마다 영상을 잘라 움직여서 카메라 내부 파라미터가 바뀜 |
| 초점 / 노출 | **길게 눌러 고정 (AE/AF 잠금)** | 촬영 중 초점이 움직이면 확대율이 조금씩 바뀜 |
| HDR, 인물 모드, 필터 | 끄기 | |

체커보드 보정 영상도 **같은 설정**으로 찍습니다.

## 장면

- 카메라에서 천까지 **0.8–1.2 m**, 카메라 높이는 천 가운데보다 조금 위(1.2–1.4 m), 살짝 내려다보게
- **문틀, 가구 모서리, 벽 모서리 같은 세로선이 2개 이상** 천과 팔에 가리지 않게 화면에 들어오게 (v7은 이 선들로 중력 방향을 찾습니다)
- 화면 **아래쪽 15 %에 바닥이 보이게** (바닥의 높이에 씀. 세로선이 없으면 바닥 평면으로 중력 방향). 천이 화면 아래 끝까지 내려오지 않게
- 천은 화면 가운데, 천 전체가 화면의 1/4 이상을 차지하게. 배경은 천과 색이 다를수록 좋음 (흰 벽 앞은 피하기)
- 조명은 밝고 고르게. 천에 강한 그림자가 생기지 않게

## 동작 (한 take 20–30초)

1. **처음 2초**: 천 없이 빈 장면 (선택, 배경 확인용)
2. **등록 자세 2초**: 천의 **32 cm 변의 두 모서리를 양손으로 잡고**, 천을 카메라 쪽으로 평평하게 펴서 정지.
   네 모서리가 모두 보여야 합니다 (아래 모서리가 손이나 몸에 가리지 않게). 이 프레임에서 모서리 4개를 클릭합니다
3. **천천히 손을 좁혔다 벌리기 2–3번** (잡은 변 길이 → 약 15 cm → 다시 펴기, 한 번에 약 4초). 10 cm보다 많이 모으거나 비틀지 마세요
   (손 위치 오차가 손 간격에 비해 커져 시뮬레이션이 혼돈적이 됨). 천이 처지는 모양에 강성의 상한이 드러납니다
4. **옆으로 천천히 옮기고, 멈추고, 작게 흔들기** 몇 초. 멈춘 뒤 천이 흔들리다 가라앉는 모습에 **공기 저항**이 드러납니다. 손은 카메라와 같은 거리를 유지 (앞뒤로 움직이면 깊이 오차가 손 궤적에 들어감)
5. 손가락은 **모서리만** 잡기. 손이나 팔이 천의 다른 부분을 가리지 않게. 천을 놓거나 뒤집지 않기

**take 3개 이상**을 찍으세요: 하나로 맞추고, 나머지로 검증합니다 (보고서에 모두).

## 모서리 이름 (노트북이 자동으로 붙이는 순서)

```
   c0 ●━━━━━━━━━━ HEIGHT_CM ━━━━━━━━━━● c3        ← 양손이 잡는 변 (c0 = 왼손, c3 = 오른손, 카메라에서 볼 때)
      ┃                                  ┃
   WIDTH_CM                          WIDTH_CM
      ┃                                  ┃
   c1 ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━● c2
```

## 찍은 뒤

Colab 노트북([notebooks/DL_Assignment02_Real2Sim.ipynb](../notebooks/DL_Assignment02_Real2Sim.ipynb))의 ①에서 천 영상과 체커보드 영상을 올립니다.
노트북이 체커보드로 카메라를 보정하고, 영상을 960 폭으로 줄이고, 프레임 번호가 적힌 그림을 보여 줍니다. 거기서
등록 프레임(천을 평평하게 편 프레임), 시작·끝 프레임을 골라 적으면, ②에서 SAM 2 마스크로 모서리 4개(c0–c3)를 자동으로 찾습니다
(틀리면 직접 좌표를 넣는 칸이 있습니다).
체커보드를 못 찍었다면 등록 프레임 천의 소실점으로 초점거리를 추정하지만, **수업 영상에서 25 % 틀렸습니다**. 체커보드를 꼭 찍으세요.

## 자주 하는 실수

- 손떨림 보정을 켠 채로 찍음 → 카메라 보정이 맞지 않아 크기·깊이가 틀어짐
- 등록 프레임에서 아래 모서리가 가려짐 → 모서리 클릭이 부정확 → scale이 틀어짐
- 천을 너무 가까이(0.5 m 안쪽) → 천이 화면을 벗어나고 depth 모델이 부정확
- 노트북 ⓪의 `HEIGHT_CM`(두 손이 잡는 변)과 다른 변을 잡음 → 메쉬와 맞지 않음 (모서리 이름 c0–c3이 달라짐)
- 세로선이 화면에 하나도 없음 → 중력 방향을 바닥 평면에만 의존 (천이 아래로 내려오면 틀어짐)
